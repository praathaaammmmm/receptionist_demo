Callback tasks and the call log are written to this demo's sample database through the same services the dashboard uses. Nothing books an appointment.

  • This is a browser-based interactive prototype. It uses sample, demo data.
  • It is not connected to a live clinic telephone number, and no real call is placed or received.
  • It does not provide medical advice. Urgent symptoms are told to call 112.
  • It records workflow outcomes (callback tasks and a call log) but is not a production recording system.
  • Microphone transcription is processed by this demo server and is not stored: each phrase is transcribed in memory and discarded. Audio is not sent to Google or any other speech service.
